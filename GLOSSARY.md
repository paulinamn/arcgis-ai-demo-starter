# Glossary

One name per concept, used identically in the code, the UI, and conversation about
this project.

Leave this file empty until a term actually needs pinning down — a concept the code
names three different ways, or a word that means something narrower here than in
ordinary English. Entries get added when they're earned, not upfront.

## Format

### Term

What it means here. If a plausible synonym is deliberately *not* used, say so and
say why — that's usually the most valuable part of the entry.
